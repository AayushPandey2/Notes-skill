# `/scribe-practice`

Resolve the Scriptorium base directory (`../scriptorium/` or the host's installed skills directory). Read its `router.md` and dispatch `/scribe-practice $ARGUMENTS`, saving the practice set inside the centralized `Practice Sets/` folder at the same sibling directory level as the `<subtopic>/` folders.
