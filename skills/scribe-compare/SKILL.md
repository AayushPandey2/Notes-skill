# `/scribe-compare`

Resolve the Scriptorium base directory (`../scriptorium/`, `~/.gemini/config/skills/scriptorium/`, `~/.claude/skills/scriptorium/`, or `~/.codex/skills/scriptorium/`). Read its `router.md` and dispatch `/scribe-compare $ARGUMENTS`. Use the matching command playbook and the per-note loading rules.
