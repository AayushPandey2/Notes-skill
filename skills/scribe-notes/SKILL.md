# `/scribe-notes`

Input: the learner's request and sources; an explicit vault path if given. Never ask *"which type of notes do you want?"* or pause for pre-write reverification—infer intent, format, and structure directly from the user's message. If only a topic name is supplied, default automatically to comprehensive from-scratch `M1` deep notes ([router.md](../../router.md)). Use one 3-file bundle for a focused single concept, or `00 - Map of Contents.md` plus a separate 3-file bundle per subtopic when the topic has distinct sub-branches. Resolve destination silently via [the destination gate](../../docs/procedures/authoring/pre-gen-gate.md) before writing. A video request uses Command V in the [command playbooks](../../docs/procedures/authoring/command-playbooks.md) when transcript or media access is available.

Follow [the direct-authoring workflow](../../core/runtime_pipeline.md) and the [root authoring rule](../../SKILL.md#scriptorium). Load only the selected master and relevant variant, knowledge-type subtemplate, and policies via [the reference index](../../docs/README.md). Source-only means no outside browsing; distinguish any labeled expansion the user permits. Teach prerequisites before first use, explain equations and worked examples at the requested depth, and cite actual source locations.

Output: a 3-file bundle in final Obsidian Markdown for each newly generated content topic—(1) the main note, (2) its companion lab under [the lab contract](../../docs/procedures/authoring/experimental-lab.md), and (3) its companion cheatsheet & interview Q&A pack under [the cheatsheet-interview contract](../../docs/procedures/authoring/cheatsheet-interview.md)—along with only needed, inspected assets at the authorized destination. Complete [visual acquisition and saved-embed checks](../../docs/procedures/authoring/representations.md). Review actual files with [verification-checklist.md](../../docs/procedures/review/verification-checklist.md); preserve unrelated notes, custom properties, and assets. If source access, download, image inspection, execution, or Obsidian rendering is unavailable, report the specific limit and do not claim it was verified.
