# `/scribe-distill`

Resolve the Scriptorium base directory (`../scriptorium/`, `~/.gemini/config/skills/scriptorium/`, `~/.claude/skills/scriptorium/`, or `~/.codex/skills/scriptorium/`), read **only** `## Command D` in `references/command_playbooks.md` plus `references/cheatsheet_template.md`, and execute it for `$ARGUMENTS`.
