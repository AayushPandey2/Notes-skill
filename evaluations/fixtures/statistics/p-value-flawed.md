# Understanding $p$-Values in Hypothesis Testing

When a statistical test produces $p = 0.03$ at significance level $\alpha = 0.05$, this means there is only a $3\%$ probability that the null hypothesis $H_0$ is true, and a $97\%$ probability that the alternative hypothesis $H_1$ is true.

Because $p < 0.05$, we conclude that the observed effect is both scientifically large and practically important.
