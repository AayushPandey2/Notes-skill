# Evaluation Rubric: Presentation, Math & Navigation (Evaluation-Only)

*Load only during evaluation or when explicitly requested as an evaluation rubric—do not load during normal note authoring. Apply presentation expectations proportionally to the active format (`M3` compact/atomic notes omit TOC and extended visuals).*

| Dimension | Pass Standard (Cite Supporting Passage) | Automatic Fail Trigger |
|---|---|---|
| **YAML & Placement** | Valid line-1 YAML for new notes, matching the active profile. Standard Properties use role-specific `note_type` and distinct IDs when assigned. Existing note revisions preserve user metadata. | Unauthorized keys, missing frontmatter on a new note, or leaked scaffold comments |
| **Math Formatting & Folds** | Native math delimiters, flush-left body displays, unambiguous table delimiters, descriptive derivation folds where needed, and quoted blank lines inside callouts. Derivation folds do not recurse. | Broken equations or table cells, reliance on color for meaning, skipped algebraic steps, or fragmented micro-folds |
| **Visuals & Tables** | Follows 5-level hierarchy; inspected local embeds with adaptive sizing, ordinary Markdown attribution, diagram-to-model correspondence, zero Mermaid/ASCII | Uninspected/broken embeds, raw HTML `<span>` attribution, or Mermaid/ASCII diagrams |
| **Link & Reference Hygiene** | Resolved wikilinks, reciprocal links only to existing artifacts, dynamic assessment/Q&A tier numbering matching actual count | Broken/fabricated wikilinks, mismatched `Q1–Q5` headings, or unquoted callout blank lines |
| **Representation coverage and readability** | Material spatial or procedural relationships have a legible adjacent representation or sufficient fallback. Prose is segmented along teaching boundaries. | Decoration substitutes for the governing relationship, essential reasoning is hidden, or a dense list substitutes for explanation |
