# Evaluation Rubric: Theory Quality (Evaluation-Only)

*Load only during evaluation or when explicitly requested as an evaluation rubric—do not load during normal note authoring. Apply only criteria relevant to the intended artifact (`M1`/`M2` theory vs. compact `M3` vs. strict-source note) rather than penalizing intentionally omitted material. Scored dimensions align with the 10 weighted rubric criteria in [benchmark-protocol.md](../benchmark-protocol.md) (`>=85/100` target and `>=4/5` in applicable essential educational dimensions for `M1`); source integrity, safety, authorization, and non-execution remain mandatory non-overrideable conditions.*

Every criterion requires **citing exact passages** from the generated note. Author self-attestation (e.g., *"I verified this checklist"*) never counts as passing evidence.

| Dimension (M1 Weight) | Pass Standard (Cite Supporting Passage) | Automatic Fail / Override Trigger |
|---|---|---|
| **Beginner Accessibility (15)** | Opens with plain-language intuition, concrete scenario, and simpler baseline before dense formalism; paces complexity without confounding simpler words with accessibility | Opens with jargon-heavy reference summary assuming unintroduced prerequisites or invokes untaught tools/methods |
| **Self-Contained Knowledge (10)** | Teaches essential terminology, symbols, central mechanisms, core math ops, assumptions, derivations, and limits locally within declared scope without external-note dependence | Relies on external links or bare `Prerequisites:` lists to supply essential unmastered knowledge |
| **Theory Completeness (15)** | Core concepts reach target depth (`Level 3–5`); comprehensive `M1` covers foundations/baselines, mechanism, key task types/variants, practical config, limitations, comparisons, and primary references | `M1` note degenerates into a narrow formula summary omitting central pillars, or leaves core mechanisms at `Level 1–2` |
| **Factual Accuracy (10)** | Definitions, theorems, equations, library behaviors, version caveats, and misconceptions match authoritative subject truth | Any Critical factual error, wrong sign/operator, library-variant conflation, or unqualified overclaim |
| **Mathematical Teaching (15)** | Motivates formulas before introducing them, climbs the abstraction ladder cleanly, explains equation anatomy/operations, keeps milestones/assumptions visible with folds closed, completes derivations | Formula dumping, skipped derivation/algebraic jumps, dimension/normalization error, stipulated definition treated as theorem, or fold-only milestones |
| **Conceptual Reasoning (10)** | Establishes need, causal mechanism (*how* and *why*), conceptual discrimination, state carryover, and interpretation independently of bare equations | Technically correct definition or topic mention substitutes for causal explanation or confuses commonly conflated terms |
| **Visual Teaching (8)** | Distributes multiple specialized, verified existing web-sourced (or supplied) images across relevant sections when permitted with attribution and adjacent before/image/caption/after narrative, or documents search refinement + honest prose/table fallback without ever generating images | Any AI/native-generated image, programmatic plot, custom SVG, redrawn art, Mermaid/ASCII, 0–1 token visual on a visually rich topic without disclosed retrieval failure, disconnected gallery, or unverified/placeholder embed |
| **Examples & Independent Application (7)** | Progressive/continuous worked traces (multi-round + unseen inference where iterative, fading scaffolding where warranted) and prediction/diagnosis/transfer checks | Single-round incomplete trace, trivial numeric substitution, or exercises requiring untaught knowledge |
| **Writing Tone & Continuity (5)** | University-textbook prose with natural pauses, chapter continuity, and clear causal transitions | Compressed research-paper shorthand, multi-step dense sentences, robotic meta-headings, internal-template leakage, or disconnected sections |
| **Formatting & Reading Experience (5)** | Native Obsidian H1–H4 headings, semantic callouts (`[!info]`..`[!abstract]-`), 3 progressive disclosure layers, spacing, and compact tables cleanly applied | Broken callouts/tables, oversized collapsed blocks, wide formula-stuffed cells, fragmented prose, or hidden essential reasoning |
| **Mandatory Integrity Conditions *(Non-overrideable)*** | Honors active `source_policy` permissions, safety boundaries, non-execution rules, domain neutrality (no leaked ML boilerplate in non-ML topics), and epistemic distinctions | Critical correctness, safety, source-integrity, or essential-prerequisite defects; fabricated assets/citations; or script generation |
