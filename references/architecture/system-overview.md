# Scriptorium structure

The [root skill](../../SKILL.md) selects one of four public commands. [Note routing](../../router.md) chooses one of seven output masters. The [reference index](../README.md) points to the selected variant, knowledge-type subtemplate, teaching move, or conditional workflow. Declarative YAML and JSON map names to instructions; they do not execute those instructions.

For a note request, resolve permitted sources and the vault destination, read only relevant guidance, research with available tools, draft Markdown directly, review it, save intended files, then inspect the saved result. Existing-note Q&A remains read-only, quizzes proceed one turn at a time, and folder configuration changes only destination settings. See [migration history](../contracts/migration-notes.md) for the guarantees lost with the former engine.
