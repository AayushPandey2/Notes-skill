# Scriptorium Metadata Policies

This directory defines the single authoritative metadata contract enforced by Engine E6 (`scriptorium/engines/vault.py`):

- [properties-policy.md](properties-policy.md) — Mandatory Obsidian YAML Properties block at the top of every generated note, optional fields, validation rules, and safe incremental update preservation.
- [tag-taxonomy.md](tag-taxonomy.md) — Central hierarchical tag vocabulary (`domain/`, `master-topic/`, `subdomain/`, `concept/`, `type/`, `level/`, `skill/`) and synonym normalization.
- [note-naming.md](note-naming.md) — Consistent filename conventions, sibling folder placement, and multi-artifact topic alignment.
