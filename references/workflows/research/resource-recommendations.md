# Further-learning resources

Use this contract when recommending further-learning resources (under Mode `R-R` or in the revision/further-learning section of a deep-study note). **Learning resources are strictly distinct from factual research citations:** a source cited to verify a theorem or API behavior is not automatically a good pedagogical recommendation for a beginner, and an accessible tutorial is not automatically a primary authority for factual verification.

## 1. Selection & Evaluation Criteria

Evaluate candidate resources (`textbook`, `academic_lecture_notes`, `official_documentation`, `course`, `video_lecture`, `educational_tutorial`, `interactive_visualization`, `coding_exercise`, `practice_platform`, `original_paper`, `maintained_repository`, `reference_manual`) across:

1. **Learner level (`beginner`, `intermediate`, `advanced`):** Beginners receive intuitive lectures, introductory textbook chapters, simple implementations, and interactive visualizations; advanced learners receive original papers, formal proofs, and deep theoretical/system references.
2. **Objective & prerequisite alignment:** Match the specific concept objectives and declare prerequisites explicitly.
3. **Accessibility & cost (`free`, `freemium`, `paid`, `institutional`, `unknown`):** When free resources are requested, select only legally accessible free material whose availability is verified; list paywalled alternatives separately and never represent paid courses as free.
4. **Specificity:** Never emit vague advice (`"Read documentation"`, `"Watch YouTube"`, `"Read research papers"`). Every recommendation must carry a verified `title`, `author_or_institution`, `canonical_url` (or explicit offline/library identifier), `section_or_chapter` where known, `learner_level`, `prerequisites`, `why_useful`, and `priority` (`essential` or `optional`).
5. **Curated sizing (no resource dumping):** Default to a compact, high-signal set (`3–5` resources); expand only when the user explicitly requests an extensive reading list.

## 2. Pedagogical Progression Order

Order recommended resources along a clear learning progression adapted to the subject:

1. `conceptual_foundation`
2. `formal_explanation`
3. `worked_examples`
4. `practical_implementation`
5. `advanced_theory`

## 3. Provenance & Verification Rule

Never fabricate a resource title, author, chapter, URL, or free-access claim. Exclude unverified or bare root-domain links and disclose when resource access could not be checked (e.g., offline environment).
