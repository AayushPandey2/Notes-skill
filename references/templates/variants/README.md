# Template Variants

Each variant specializes one parent master (`M1`–`M7`) without duplicating its parent specification.

| Variant | Parent Master | Role |
|---|---|---|
| [lecture-order.md](lecture-order.md) | M2 (`study-notes`) | Preserves sequential chapter, lecture, transcript, or source progression with inline examples |
| [formula-sheet.md](formula-sheet.md) | M3 (`quick-reference`) | Compact formulas with symbol definitions, units, and applicability conditions |
| [syntax-reference.md](syntax-reference.md) | M3 (`quick-reference`) | Workflow-organized API signatures, copy-vs-view semantics, and cookbook recipes (`api-table`) |
| [command-reference.md](command-reference.md) | M3 (`quick-reference`) | CLI commands, flags, typical workflows, and safety warnings |
| [atomic-card.md](atomic-card.md) | M3 (`quick-reference`) | Transcludable `<150`-word single-concept Obsidian card (`atomic`) |
| [flashcards.md](flashcards.md) | M6 (`assessment`) | Front/back active-recall flashcards with concise answers and traps |
| [mock-exam.md](mock-exam.md) | M6 (`assessment`) | Timed/progressive mock exam & viva preparation with hidden rubrics |
| [comparison-guide.md](comparison-guide.md) | M7 (`synthesis-revision`) | Decision-first trade-off matrix, causal divergence & crossover edge case (`comparison`) |
| [paper-breakdown.md](paper-breakdown.md) | M7 (`synthesis-revision`) | Research paper deconstruction, equations & ablation audit (`paper-breakdown`) |
| [quick-summary.md](quick-summary.md) | M7 (`synthesis-revision`) | Verified article/docs/timestamped video deconstruction (`summary`) |
| [revision-pack.md](revision-pack.md) | M7 (`synthesis-revision`) | Multi-note exam revision pack consolidating definitions, formulas & links |
| [concept-map.md](concept-map.md) | M7 (`synthesis-revision`) | Mermaid relationship map and semantic connection matrix across concepts |
