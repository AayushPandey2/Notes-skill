# Variant: Active-Recall Flashcards

- **Parent Master:** [M6 — Practice & Assessment](../masters/assessment.md)
- **Specialization:** Atomic front/back spaced-repetition cards for fast recall and misconception resistance.
- **Key Overrides:**
  1. **One testable claim per card:** Each card tests one definition, distinction, condition, complexity bound, or diagnostic cue—never multi-paragraph essays.
  2. **Hidden answer format:** Present the visible **Front** prompt, followed by an unquoted blank line and a collapsed Obsidian callout (`> [!tip]- Back`) containing the crisp answer, condition, and 1-line trap.
  3. **Objective alignment:** Order cards from recognition -> distinction -> boundary application.
