# Scriptorium Template Library

All output product templates live under one unified library:

- **[masters/](masters/README.md):** Seven canonical output product masters (`M1`–`M7`). Exactly one master owns each output artifact.
- **[variants/](variants/README.md):** Product specializations inheriting from a parent master without duplicating its full specification.
- **[subtemplates/](subtemplates/README.md):** Six knowledge-type pedagogical adaptations (`mathematical`, `computational`, `scientific`, `conceptual`, `historical`, `empirical`).
- **[modules/](modules/README.md):** Reusable instructional capabilities activated selectively by the adaptive planner (`instructional-registry.json`).

Composition formula: `Primary Master + Optional Variant + Knowledge-Type Subtemplate(s) + Selected Modules + Active Source Policy`.
