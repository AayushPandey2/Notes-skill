# Scriptorium 5 plans and prepared visual demonstrations

From the repository root, run `python examples/scriptorium-5/run.py` (or use the
project virtual environment's Python). The runner calls the real canonical
composition planner, renderer execution and offline verification APIs. It also
executes binary search and checks the displayed state transitions.

These examples contain adaptive plans and prepared visual demonstrations.
They are **not completed full-topic teaching collections**. Their canonical
plans retain open educational obligations, and no semantic review receipts are
manufactured. The authored end-to-end teaching collection remains in
[adaptive-composition](../adaptive-composition/README.md).

- [Actual measurements and chapter counts](measurements.json) record the current
  run; workload units are planning estimates, not measured learning time.
- [Renderer receipts](renderer-receipts.json) bind specifications and actual
  persisted artifacts. The runner rechecks those artifacts without network access.
- [Executed binary-search trace](executed-search-trace.json) contains the real
  inputs, exclusive upper bounds, midpoints, decisions and resulting index.
- [Narrow request route](narrow-route.json) records the actual quick-reference
  route, with no renderer or retrieval calls.

The galleries demonstrate geometric coordinates and a scientific curve,
attention interfaces and a typed table, engineering connectivity, algorithm
states, native Mermaid, a constrained HTML state viewer, and historical
chronology. The `plans/` directory contains the original concept inventories,
prerequisites, depth requests, allocation rationale and canonical composition
plans for mathematics, AI, engineering, computer science and history.

Open the galleries inside `vault/6 - Full Notes/` in Obsidian. SVG assets live in
`vault/assets/scriptorium/`; interactive HTML opens through a relative file link.

Native Mermaid is persisted source rendered by the host, not a claimed raster
export. The HTML viewer steps through supplied, executed algorithm states; it
does not execute arbitrary supplied programs or simulate physical systems.

Graphs describe connectivity or sequence. The engineering graph is not a
circuit-symbol drawing or circuit simulator, and historical arrows do not prove
causal explanations. The runner checks SVG syntax and artifact digests; browser
appearance and full pedagogical correctness are outside these demonstrations.

Remote media acquisition is separately covered by the regression tests. Its
built-in decoder supports noninterlaced 8-bit grayscale/RGB/alpha PNG only, with
bounded bytes, pixels, redirects and acquisition time. Other external raster
formats, external SVG and AI image generation need explicit host adapters.
These examples perform no network acquisition and make no license-verification
claim. No performance improvement is asserted without a comparison baseline.
