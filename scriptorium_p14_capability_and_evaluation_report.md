### Minimal host capability contract and decision needed

A future host may supply a purpose-built operation such as `acquire_existing_image(source_url, destination)`. That is a **proposal, not an existing tool**. It should honor the resolved source policy and network approval, accept an authorized existing image URL, save only to permitted staging without overwriting unrelated files, return the verified path, actual media type and byte size (and dimensions where supported), and report failures. It must treat external content as data. The agent must still choose educationally useful sources, assess rights and scientific accuracy, inspect the saved image, align it with the lesson, and attribute it.

The smallest external decision is to use a host exposing such a constrained native capability, authorize its implementation as host infrastructure, or continue producing honest fallback notes while accepting that applicable local-visual requirements cannot pass in this host. **This phase did not authorize or implement a new downloader, install a plugin, add credentials, or relax the non-execution contract.**

## EP14 evaluation standardization

The previous benchmark sentence said “individual artifact weighted average (75%) + cross-artifact consistency ... (25%)” without defining member weights. For a standard theory/lab/mastery bundle, **EP14 applies prospectively**:

`Bundle = 0.75 × (0.50 × Main + 0.25 × Lab + 0.25 × Mastery) + 0.25 × Consistency`.

The effective final shares are Main 37.5%, Lab 18.75%, Mastery 18.75%, Consistency 25%. The main note has the primary educational objective; companions and cross-file consistency retain substantial independent influence. For a different legitimate composition, predeclare member weights summing to one within the artifact share before inspecting outputs. A required missing artifact is a failure, not an opportunity to redistribute weight. Applicable essential floors, Critical overrides, material source violations, and missing required artifacts still override a passing aggregate. Prompt 10 and Prompt 12 scores are preserved under their original conventions; previously calculated alternate totals remain sensitivity analyses, not corrected historical scores.

EP14 also prospectively distinguishes visual-unnecessary tasks, visually rich and asset-permitted M1 work, strict-source prohibitions, documented host blockage, unsupported external links, and fabricated or misleading visual evidence. A truthful table/prose fallback receives credit for its actual educational help, but does not itself satisfy a still-applicable local-visual outcome or M1 essential floor. Strict-source obedience is not a source-fidelity failure. An external URL is not a saved and inspected local image. Fabricated inspection or nonexistent embeds remain subject to existing overrides. The evaluation file change is ten added lines and two replacements; `git diff --check` passed.

**Residual runtime/evaluation tension:** the shared `docs/procedures/review/theory-rubric.md` says a documented retrieval failure can justify declaring Visual Teaching inapplicable on a visually rich topic. EP14 interprets host blockage more narrowly for asset-permitted M1 benchmark objectives. That shared file also governs runtime acceptance, so it was intentionally left unchanged. EP14 standardizes independent evaluation, **not** runtime publication semantics. Any runtime wording correction needs a separate confirmed defect, candidate identity, and focused validation.
