# Subtemplate: Conceptual

- **Purpose:** Realize the [12 teaching layers](../../../core/teaching_core.md) for concepts, definitions, mechanisms, comparisons, and general/non-quantitative domains with short 1–3 sentence paragraphs, concrete upfront examples, and explicit contrast tables.
- **Activation conditions:** Conceptual mastery, definitions, classifications, comparative choices, or general domain explanations (`conceptual`, `comparative`).
- **Expected inputs:** Concept identity, learner's problem, 3-tier prerequisite plan, source policy, tiny concrete opening fixture, counterexamples, and boundary conditions.

> **Authoring-agent image instruction:** Before drafting, identify the visual learning needs at each conceptual inflection point. Acquire suitable images where they materially improve understanding. Inspect the saved images, then compose the explanation around their actual visible content. Do not treat image placement as an optional finishing step.

- **Realizing the 12 Teaching Layers:** Start with Goal/Prerequisites/TOC when comprehensive → tiny concrete table + real-world applications table + clarify misleading names (Layer 1) → small multi-column example before defining terms + Vocabulary Dictionary with clash/myth warnings (Layer 2) → prove concretely why a simpler rule fails + contrast table (Layer 3) → local foundation terms before formal definitions with positive, non-example, and boundary cases (Layers 4–5) → decode inflection-point structural/contrast visuals (Layer 6) → trace `Starting state → operation → reason → intermediate change → outcome` (Layer 7) → carry one running example through assumptions, explicit **"What this does NOT require/mean"** section, `Mistake | Correct approach` table, and multi-option comparison (Layers 8–11) → close comprehensive guides with a Rule Cheat Sheet, Beginner/Intermediate/Advanced Q&A, worked reasoning checks, and an N-step Mental Model (Layer 12).
- **Domain expectations (General & other domains):** Use domain-appropriate concepts, evidence, mechanisms, procedures, or comparisons; never force mathematical or computational machinery onto unrelated subjects.
- **Prerequisite bridges:** Apply the 3-tier rule (explain essential concepts locally; bridge secondary terms; bound outside topics with links).
- **Visual opportunities:** Follow [representations.md](../../procedures/authoring/representations.md) using complementary downloaded raster figures for structural contrasts and classifications, plus native Mermaid for taxonomies, decision trees, and flows.
- **Evidence, practice & failure handling:** Cite locators when source-bound (`[UNVERIFIED]` if unconfirmed); repair dense walls of prose, definitions without concrete tables, or links replacing essential local explanation via [verification-checklist.md](../../procedures/review/verification-checklist.md).
