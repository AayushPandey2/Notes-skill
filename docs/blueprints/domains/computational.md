# Subtemplate: Computational

- **Purpose:** Realize the [12 teaching layers](../../../core/teaching_core.md) for Machine Learning, Deep Learning, algorithms, and software systems theory—delivering crisp, zero-prerequisite conceptual/mathematical understanding in theory notes while keeping full multi-track labs inside the fixed companion lab.
- **Activation conditions:** ML/DL theory, algorithms, data structures, system architectures, state transitions, or complexity analysis (`programming`, `algorithmic`, `architectural`, `procedural`).
- **Expected inputs:** Problem/task contract, tiny concrete dataset/state table, upfront **Symbol Dictionary** (with clash notes), local math/complexity foundations, scalar-to-vectorized progression, deterministic running fixture, and boundary/failure regimes.

> **Authoring-agent image instruction:** Before drafting, identify the visual learning needs at each conceptual inflection point. Acquire suitable images where they materially improve understanding. Inspect the saved images, then compose the explanation around their actual visible content. Do not treat image placement as an optional finishing step.

- **Realizing the 12 Teaching Layers:** Open with Goal/Prerequisites/TOC → tiny input-to-output table + real-world applications table + explain misleading naming (Layer 1) → multi-column dataset table + upfront **Symbol Dictionary** + notation-clash note (Layer 2) → plug numbers into the simpler model/algorithm to prove why it breaks + contrast visual + comparison table (Layer 3) → local math/complexity foundations with value tables (Layer 4) → end-to-end stage diagram (downloaded web figure) + **1-feature scalar → multi-feature sum table → vectorized matrix form with shape check** (Layer 5) → equation `Part | Purpose` table + **negative / zero / positive / limit checks** + paired curve/derivative & geometric boundary visuals (Layer 6) → derive objective/update from first principles + numerical stability notes (Layer 7) → walk one tiny 4-row fixture through **Iteration 1 → Update → Iteration 2** tables (Layer 8) → define every evaluation metric/confusion matrix around **one shared fixture** + ROC/PR/calibration visuals (Layer 9) → regularization/hyperparameters + assumptions + explicit **"What it does NOT require"** + preprocessing/leakage rules (Layers 10–11) → close with `Mistake | Correct approach` table, multi-algorithm comparison, and N-step Mental Model (Layer 12), handing off the Formula/Rule Cheat Sheet, tiered Beginner/Intermediate/Advanced Q&A (tap-to-reveal), and worked problems to the companion Cheatsheet & Interview Q&A file.
- **Domain expectations (ML, DL & Systems):**
  - *Machine Learning:* Cover task, data, hypothesis, prediction, loss, optimization, metrics/calibration, regularization, assumptions (and myths), preprocessing/leakage, parameters vs. hyperparameters, and training fit vs. generalization; leave full multi-track coding labs to the companion lab.
  - *Deep Learning:* Build scalar neuron → vector layer → matrix batch, forward pass, loss, chain-rule gradients, saturation, and updates progressively with explicit `(m, n)` shape verification.
  - *Systems:* Trace one complete concrete request/event end to end through components, state, trust boundaries, and failure/recovery rather than stopping at a box diagram.
- **Visual opportunities:** Follow [representations.md](../../procedures/authoring/representations.md) using **at least 4–5 inspected local web raster images** at inflection points (baseline contrast, foundation curves, activation+derivative saturation, linear vs. polynomial/transformed boundaries, ROC/calibration, L1/L2 geometry, under/overfit, and architecture/pipeline diagrams); never use Mermaid or ASCII graphs.
- **Evidence & failure handling:** Bind equations via [math_gates.md](../../../core/math_gates.md); keep any illustrative snippet in theory notes labeled `Status: static review (not executed)` if unexecuted; repair missing shape checks, silent symbol clashes, or unsupported outputs via [verification-checklist.md](../../procedures/review/verification-checklist.md).
