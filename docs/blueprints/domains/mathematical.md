# Subtemplate: Mathematical

- **Purpose:** Realize [teaching_core.md](../../../core/teaching_core.md) and [math_gates.md](../../../core/math_gates.md) for theorems, derivations, quantitative relations, and proofs—building every prerequisite mathematical tool from scratch with small concrete examples, scalar-to-vector progression where appropriate, and explicit step-by-step transitions.
- **Activation conditions:** Displayed equations, formal derivations, proofs, quantitative modeling, or worked numerical problems (`mathematical`).
- **Expected inputs:** Governing equations, progressive symbol introductions (with trailing **Notation Reference** when needed), local foundation tools, assumptions, full derivation transitions, and one consistent running example.

- **Realizing the Conceptual Flow:** Open with separated `Difficulty / Prerequisites / Learning objectives` + clickable TOC → introduce one conceptual burden at a time with concrete intuition → local prerequisite foundations → early worked example introducing symbols progressively (reserving any Notation Reference for the end) → limitations of simpler rules → concept-appropriate math depth per [math_gates.md](../../../core/math_gates.md) (bridge before formula, explicit transitions with no `"rearranging gives"` leaps, `> [!example]- Understand this formula step by step` beneath coherent top-level displayed `$$...$$` blocks, `aligned` derivations, `cases` where needed) → explicit distinction between **definition, assumption, identity, approximation, numerical illustration, and formal proof** → counterexamples and boundaries → concise synthesis, optional Notation Reference, and links to any generated companions.
- **Domain expectations (Mathematics):** Prioritize definitions, assumptions, derivations or proofs, counterexamples, and generalization; adapt formula walkthroughs to proof statements without forcing artificial numerical substitutions.
- **Visual opportunities:** Follow [representations.md](../../procedures/authoring/representations.md) using inspected local raster plots at inflection points (foundation curves alongside tables, function + derivative pairs, before/after geometric transforms, and constraint regions).
- **Formalism, evidence & failure handling:** Enforce [math_gates.md](../../../core/math_gates.md); distinguish source derivations from added bridges; repair jumped cancellations, missing symbol definitions, or unbridged matrix expressions via [verification-checklist.md](../../procedures/review/verification-checklist.md).
