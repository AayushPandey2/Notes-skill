# M1 — Deep Learning Notes

- **Master ID:** `M1` (`deep_notes` / compatibility route `deepstudy-master`)
- **Primary intent:** `comprehensive_learning` — build complete first-principles understanding from the learner's baseline to requested mastery.
- **Activation signals:** "teach me from scratch", "explain deeply", "comprehensive notes", "from fundamentals to advanced", or bare `/scribe-notes <topic>` without an explicit alternate product format.
- **Non-activation:** Do not select M1 when the user primarily requests a compact cheat sheet (`M3`), solved problem set (`M4`), implementation/build guide (`M5`), quiz/flashcards (`M6`), or standalone comparison/revision pack (`M7`).
- **Load as needed:** [teaching rules](../../../core/teaching_core.md), [adaptive planning](../../procedures/authoring/adaptive-engine.md), [research](../../procedures/sourcing/research-engine.md), [source fidelity](../../procedures/sourcing/source-fidelity.md), [authoring rules](../../../core/authoring_rules.md), and [math guidance](../../../core/math_gates.md).
- **Output profile:** Comprehensive collections use the five-key YAML profile in [properties policy](../../properties/properties-policy.md); single or existing notes use their appropriate Obsidian properties without rewriting user-managed fields.

## Orientation

Give the bounded topic, central question, observable objectives, and learning roadmap. Prepare only prerequisites the learner needs (`assume`, `remind`, `bridge`, `teach`, or `defer`). Apply the appropriate line-1 YAML profile from [properties policy](../../properties/properties-policy.md); keep planning records outside the finished note.

## Core learning sequence

Order concepts by essential prerequisites, preserving source sequence with local bridges for source-grounded notes. Establish definitions and notation before use. Load and follow the matching knowledge-type subtemplate (`conceptual`, `mathematical`, `computational`, `scientific`, `empirical`, or `historical`) and only needed teaching moves at the depth the learner requires. Mathematics, code, proofs, diagrams, chronology, and experiments remain conditional.

Compose one coherent, beginner-respectful explanation following [teaching_core.md](../../../core/teaching_core.md) (patient one-to-one mentor voice, question-driven headings adapted to the topic, and the 20-step novice-first authoring flow)—never dump equations before motivation and intuition, never pack multiple major concepts into sparse summary bullets, and always bridge formulas via **Question → intuition → visual meaning → symbols → formula → calculation → interpretation → check** ([math_gates.md](../../../core/math_gates.md)). Carry one stable running example across vocabulary, visuals, mechanism, and calculation, and test transfer on a second example. Plan and acquire complementary visuals through [representations.md](../../procedures/authoring/representations.md), inspect saved images before writing around them, and teach every visual via the six-phase narrative (Set question → Show → Decode → Trace → Connect & limits → Check). Explain differences between alternatives causally before summary tables, place misconception corrections beside the confusing step, put consequential assumptions beside claims, and review against [verification-checklist.md](../../procedures/review/verification-checklist.md).

## Integration and assessment

Connect concepts through synthesis or cross-topic vault bridges (`P08`) without repeating prior chapters. Verify stated objectives through recall, calculation, derivation, diagnosis, or source interpretation without arbitrary question quotas.

## Revision and further learning

Provide Layer B structured concept review and concise retrieval cues (`P11`) preserving all applicability conditions, plus separately curated further-learning resources ([resource-recommendations.md](../../procedures/sourcing/resource-recommendations.md)) when helpful. Use [footer_widgets.md](../../../core/footer_widgets.md) only for active vault workflows.

## Quality & validation gate

Review ARRIE source coverage/citations, pedagogical quality, formula folds, and local visual embeds against [verification-checklist.md](../../procedures/review/verification-checklist.md) before finishing. Repair the smallest affected region rather than regenerating the entire note.

**Activation examples:** Domain-independent comprehensive learning requests (e.g., first-principles derivations with code, visual analysis, or systematic conceptual foundations).  
**Non-M1 examples:** Compact cheat sheets -> `M3`; solved problem sets -> `M4`; pure implementation guides -> `M5`; comparisons/revision packs -> `M7`.
