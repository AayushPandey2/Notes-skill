# Subject Theory Blueprint: Computer Networking

## Purpose

Teach Computer Networking as **layered protocol responsibilities, state machines, encapsulation, and end-to-end vs. hop-by-hop trade-offs** rather than isolated acronym lists.

## Core Theory Obligations

1. **Layered Encapsulation & Addressing:** Trace how application payloads are framed through transport, network (IP/CIDR/routing), and link (MAC/ARP/switching) layers, distinguishing port, IP, and link-layer addresses.
2. **Protocol State & Reliability:** Explain connection setup/teardown, sequence/acknowledgement numbers, sliding windows, flow vs. congestion control, timeouts, and retransmissions.
3. **Latency, Bandwidth & Path Dynamics:** Distinguish propagation delay, transmission delay, queueing delay, bandwidth-delay product, and packet loss.
4. **Application & Security Protocols:** Explain DNS resolution/caching, HTTP/1.1 vs. HTTP/2 vs. HTTP/3, and TLS handshake trust/encryption guarantees.
5. **Failure & Diagnosis:** Trace packet loss, reordering, duplicate ACKs, asymmetric routing, MTU fragmentation, and DNS/TLS failures.
