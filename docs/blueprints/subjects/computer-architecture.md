# Subject Theory Blueprint: Computer Architecture

## Purpose

Teach Computer Architecture through **instruction semantics, datapath/control execution, pipelining/hazards, and memory-hierarchy trade-offs**.

## Core Theory Obligations

1. **ISA & Data Representation:** Instruction formats, addressing modes, two's complement/IEEE-754 bit representations, endianness, and ABI calling conventions.
2. **Datapath, Control & Pipelining:** Single-cycle vs. pipelined stages (`IF/ID/EX/MEM/WB`), structural/data/control hazards, forwarding vs. stalling, branch prediction, and CPI/speedup (Amdahl's law).
3. **Memory Hierarchy & Parallelism:** Temporal/spatial locality, cache geometry (direct-mapped, set-associative, tags/index/offset), hit/miss/write policies, virtual-to-physical translation, SIMD/SMT/multicore coherence (MESI).
