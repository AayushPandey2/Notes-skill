# Conditional teaching moves

Load this page when a selected master needs a teaching move beyond its own instructions. These are choices for an author, not software components or checks to execute.

| Need in the request | Use when | What to add and review |
|---|---|---|
| Real-world map & naming fix | Concept has real uses or misleading name | Open with tiny concrete example table, applications table, and name clarification. |
| Motivation & failure proof | Learner asks "why not use X?" | Plug real numbers into simpler baseline to expose broken output + contrast visual. |
| Upfront symbol & local foundation | Formulas rely on unfamiliar math/tools | Include Symbol Dictionary (with clash note) + value tables & rules for needed prerequisites. |
| Scalar-to-compact progression | Equations use vectors, matrices, or sums | Teach 1-variable scalar case -> multi-variable sum + table -> compact vector/matrix form. |
| Equation & curve dissection | A displayed equation is central | Show visible `Part \| Purpose` table, test `- / 0 / + / limit` cases, and attach [math guidance](../../../core/math_gates.md) fold. |
| Multi-iteration hand trace | Concept involves iterative updates/steps | Trace Iteration 1 -> Update -> Iteration 2 on one tiny shared fixture showing loss/error drop. |
| Limits, myths & "NOT required" | Readers confuse adjacent assumptions | Contrast with counterexamples, state what is **NOT** assumed/required, and give `Mistake \| Fix` table. |
| Visual reasoning | Spatial, curve, or flow structure matters | Place at inflection points (contrast, curve+derivative, before/after, diagnostic) via [visual guidance](../../procedures/authoring/representations.md). |
| Cheat sheet, tiered Q&A & practice | Comprehensive mastery or interview prep | Close with grouped Formula Cheat Sheet, Beginner/Intermediate/Advanced Q&A, worked problems, and N-step mental model. |

Select only moves needed by the current objective. Review the actual note with [the manual checklist](../../procedures/review/verification-checklist.md).
