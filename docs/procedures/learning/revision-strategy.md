# Retention & Long-Term Learning Strategy

## Purpose

Support durable retention, spaced retrieval, and misconception repair over time—beyond single-session note creation.

## 1. Five-Stage Learning & Retention Cycle

Apply when generating revision packs (`M7` / `revision-pack.md`), study plans, or interactive `/scribe-quiz` ([mastery-design.md](../authoring/mastery-design.md)) review sessions:

1. **Initial understanding:** Read the theory note and reconstruct worked examples locally.
2. **Immediate retrieval:** Answer conceptual and mechanism checks without viewing the explanation.
3. **Delayed retrieval:** Revisit high-yield concepts and boundary traps on an **adaptive illustrative spacing default** (adjusted to exam dates, available study time, and demonstrated recall rather than a rigid fixed schedule).
4. **Interleaved application:** Mix problems across related methods so the learner must **select** the right approach before executing it.
5. **Misconception repair & transfer:** Revisit only documented weak areas and test transfer on unfamiliar scenarios.

## 2. Host Limits & Read-Only-by-Default Discipline

- Revision and vault-audit workflows remain **read-only by default**—grounded strictly in existing vault notes (`[[Note Title#Heading]]`).
- Persist weak-area tracking or modify notes only when explicitly requested; automated reminders or persistent learning-history logs require external host support and user permission (never invent learning history).
