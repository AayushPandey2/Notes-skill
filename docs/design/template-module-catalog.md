# Template and module guide

Use [router.md](../../router.md) to select one output master: M1 deep notes, M2 source-ordered study notes, M3 quick references, M4 worked solutions, M5 implementation guides, M6 assessments, or M7 synthesis and revision. The selected file is under [masters](../blueprints/formats/). A requested presentation form may add one file from [variants](../blueprints/presets/) such as `formula-sheet.md`, `lecture-order.md`, or `paper-breakdown.md`.

Select and load the matching [knowledge-type subtemplate](../blueprints/domains/) for the topic's dominant knowledge type (`conceptual`, `mathematical`, `computational`, `scientific`, `historical`, or `empirical`) so its teaching sequence, image opportunities, and completion checks govern the draft. The [module catalog](../blueprints/components/module-catalog.md) lists optional teaching moves such as prerequisite bridges, worked examples, comparisons, visuals, practice, and revision cues. Use the move that serves the learner's objective; do not load all modules by default.

[master-registry.yaml](../dispatch/master-registry.yaml) and [instructional-registry.json](../procedures/authoring/instructional-registry.json) are declarative routing aids. They do not execute, validate, install aliases, or establish that an output was checked. [Manual verification](../procedures/review/verification-checklist.md) applies to actual output.
