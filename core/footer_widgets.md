# Optional reflection footer

Load when the learner wants a reflection or review area in a note. Add a short Markdown section with what was learned, one genuine open question if any, links to **verified existing related notes** (keeping unbuilt future learning topics clearly separated in plain text), and omit empty fields, placeholders, or empty related-notes sections. A learner can record revisit dates directly in the note body if requested.

Do not embed Dataview JavaScript or a button that edits the note. This footer is optional for every master and must fit the product's length and purpose.
