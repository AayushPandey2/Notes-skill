# Optional reflection footer

Load when the learner wants a reflection or review area in a note. Add a short Markdown section with what was learned, one genuine open question if any, and links to existing related notes. Omit empty fields and placeholders. A learner can record revisit dates directly in the note body if requested.

Do not embed Dataview JavaScript or a button that edits the note. This footer is optional for every master and must fit the product's length and purpose.
